# Applications Android de ComboZen

Ce dépôt ne sert qu à une chose : distribuer les applications Android de
ComboZen, publiées automatiquement depuis le dépôt privé du produit.

Les fichiers se trouvent dans les publications (Releases) :

- `combozen.apk` — ComboZen, le suivi personnel d objectifs et d habitudes ;
- `combozen-pro.apk` — ComboZen Pro, l administration pour les praticiens ;
- `objectifs.apk` — la version de développement, sans usage public.

La dernière version est toujours à cette adresse :

    https://github.com/EmpereurPirate/combozen-apk/releases/latest/download/combozen.apk

À l ouverture du fichier, Android demande d autoriser l installation depuis
cette source : c est la procédure normale hors magasin d applications.

Le code source n est pas ici. Pour toute question : combozen@combozen.app
