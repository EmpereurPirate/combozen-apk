# Applications Android de ComboZen

Ce dépôt ne sert qu'à une chose : distribuer les applications Android de
ComboZen. Elles y sont publiées automatiquement, à chaque version, depuis le
dépôt privé du produit.

## Les fichiers

Ils se trouvent dans les publications, sous [Releases](https://github.com/EmpereurPirate/combozen-apk/releases) :

- **`combozen.apk`** — ComboZen : le suivi d'objectifs et d'habitudes.
- **`combozen-pro.apk`** — ComboZen Pro : l'administration, pour les
  praticiens inscrits au répertoire. Elle s'installe **à côté** de ComboZen,
  sans la remplacer, et n'ouvre que les personnes qui vous ont désigné.
- `objectifs.apk` — la version de développement du cabinet, sans usage public.

La dernière version est toujours à la même adresse :

    https://github.com/EmpereurPirate/combozen-apk/releases/latest/download/combozen.apk

## Installer

À l'ouverture du fichier, Android demande d'autoriser l'installation depuis
cette source : c'est la procédure normale hors magasin d'applications. Vous
n'aurez à le faire qu'une fois.

L'application vous proposera ensuite les mises à jour d'elle-même, en
comparant sa version à celle publiée ici.

Vous pouvez aussi utiliser ComboZen sans rien installer, depuis
[combozen.app](https://combozen.app/objectifs).
